# UserAgent - the person's side

What runs on the person's side of MPAI-MAS: the **browser client** (`Clients/Browser`), the workflow interpreter
(`Rca`) and the reader of the Workflow Description Language (`Wdl`), the Controller API across the network (`Remote`),
the client's own workflow, MPAI-MAS (`Orchestration`), and the avatar (`Assets`).

The client holds the microphone, the camera, the screen and the avatar, and no AI model.
