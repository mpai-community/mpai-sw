# Apps - what Thalia offers

One folder for each App: its **workflow** (`*.orch`, in the Workflow Description Language), `app.json` (its name, the
Module it runs over) and its icon. `MAS` holds the container the Apps run in; `Language` names the languages offered.

To add an App, see section 7 of the [Technical Guide](../docs/Thalia-Technical-Guide.md).
