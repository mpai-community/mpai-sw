# MAS - MPAI as a Service

`Service` is the **MPAI-MAS Service**: the program that hosts the Controller and the Modules and speaks MPAI-MAS over HTTPS;
it has its install and publish scripts for Linux (`linux`) and Windows (`windows`) and an example configuration
(`mas-server.example.json`). `Server` is the library the Service is made of: the MPAI-MAS endpoints and the catalogue of Apps.
