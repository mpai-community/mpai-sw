# AIF - the AI Framework

The MPAI-AIF software that runs a Module: the **Controller** that builds a Module's graph from its L3 and runs it,
the **Store** of L3s, the metadata and Data Type checks (`Metadata`, `PortData`), the communication channels, the
Shared and Global Storage, and the Trust and Root of Trust.

Everything here is used by the Service; nothing here knows about an App.
